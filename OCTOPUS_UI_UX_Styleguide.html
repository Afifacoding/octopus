Type scale & rules used in the app

  • Font: Inter (var(--font-sans)); antialiased; no serif anywhere.
  • Page title 18px/600 · section heading 20px/600 · card heading 16px/600 · body 14px · meta 12px · eyebrow 11px uppercase tracking-wide.
  • Radii: buttons/inputs 10–12px, cards 16px (rounded-2xl), pills 999px. Base --radius: 0.75rem.
  • Spacing: page padding 32px desktop / 16px mobile; card padding 24px; grid gap 24px; content max-width 1152px.
  • Elevation: almost flat — 1px borders + backdrop-blur header; shadows only on primary button and FAB.
  • Motion: transition 150ms on hover for buttons, nav items and cards; spinners use animate-spin.
  • Dark mode: .dark class on <html>, persisted in localStorage, toggled from header.
  • Rule: never hardcode colors — always the semantic tokens above.
